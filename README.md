## Основний функціонал
- **Процедурна генерація лабіринту:** алгоритм пошуку в глибину (DFS), що гарантує наявність виходу в кожній новій грі.
- **Керування:** підтримка як кнопок на екрані, так і свайпів (жестів) безпосередньо по ігровому полю.
- **3 рівні складності:** Легкий (`9×9`), Середній (`15×15`) та Складний (`21×21`).
- **Підказка найкоротшого шляху:** алгоритм пошуку в ширину (BFS) підсвічує оптимальний маршрут до виходу з можливістю вмикати та вимикати підказку.
- **Режим «Туман війни» (Fog of War):** обмежує видимість гравця радіусом у 2 клітинки.
- **Таймер та збереження рекордів:** автоматичний підрахунок часу проходження та збереження найкращого результату для кожного рівня складності через `SharedPreferences`.
- **Локалізація (i18n):** підтримка української (`uk`) та англійської (`en`) мов із перемиканням у реальному часі без втрати прогресу поточної гри (`onSaveInstanceState`).
- **Логування:** налаштований `java.util.logging.Logger` (`AppLogger`) із власним `LogcatHandler` для виведення подій рівнів `INFO`, `FINE`, `WARNING`, `SEVERE` під тегом `MazeGame`.

## Технології
- **Мова:** Java
- **Платформа:** Android SDK
- **IDE:** IntelliJ IDEA

## Структура проєкту
- `app/src/main/java/com/example/mazeapp/MainActivity.java` - головна активність, таймер, збереження стану та рекордів, перемикання мов.
- `app/src/main/java/com/example/mazeapp/MazeView.java` - кастомне ігрове поле (`View`), генерація DFS, пошук шляху BFS, обробка жестів та рендеринг.
- `app/src/main/java/com/example/mazeapp/AppLogger.java` - конфігурація логера для виведення у Logcat.
- `app/src/main/res/layout/activity_main.xml` - інтерфейс користувача в темно-синій темі.
- `app/src/main/res/values/strings.xml` та `values-uk/strings.xml` - ресурси локалізації.
